# 기계공학과 학부 4학년을 위한 3D ESC 미분 가능 물리 & 이상치 복구 학습 자료 — 목차 및 세부 집필 계획

## 0. 집필 원칙 및 대상 독자 설정

* **대상 독자:** 기계공학과 학부 4학년 수준
  * **이미 아는 것 (출발점):** 열전달(Fourier 전도, Newton 대류, 복사 $\varepsilon\sigma T^4$, Biot 수), 선형대수($Ax=b$, 중첩의 원리), 수치해석 기초(유한차분/유한체적 맛보기, Newton–Raphson), 자동제어 기초(PID 폐루프).
  * **아직 낯선 것 (이 자료에서 쉽게 풀어줄 대상):** 반도체 식각 ESC 도메인, 희박 기체 열전달, 축약 차수 모델(ROM), PyTorch 미분 가능 물리 & 수반법(Adjoint), 역문제 비식별성(Nullspace), 제약 최적화(SLSQP), 통계적 신뢰상한(Clopper–Pearson), PINN과의 차이.
* **집필 원칙 (3-Step 설명법):** 모든 개념은 **① 일상·기계공학 직관 비유 → ② 꼭 필요한 핵심 수식 1~2줄(물리적 의미 해설) → ③ 우리 프로젝트 실제 코드·그래프 1:1 매핑** 순서로 전개한다.
* **목표 완독 시간:** 약 2~3시간 (총 7개 챕터, 챕터당 15~25분 분량, 각 장 끝에 **"3줄 요약 + 면접 자가 점검 퀴즈 1문제"** 포함).

## 1. 전체 목차 및 챕터별 세부 내용 계획

### Chapter 1. 큰 그림 먼저 잡기: "우리가 도대체 무엇을 만들었는가?"
* **학습 목표:** 수식 없이 5분 만에 이 프로젝트의 문제 상황, 해결 구조, 최종 결과물을 남에게 설명할 수 있다.
* **출발점 (학부 지식):** 방바닥 보일러(난방) + 에어컨(냉방)으로 방 온도를 맞추는 열평형 비유.
* **세부 내용:**
  1. **반도체 플라즈마 식각 챔버의 고민:** 위에서는 플라즈마가 500 W로 지지고, 아래에서는 20°C 칠러가 식히는 샌드위치 구조. 웨이퍼 온도가 1~2°C만 틀어져도 칩 수율이 깨진다.
  2. **왜 2D가 아니라 3D 10존 히터인가?** 실제 팹에서는 "좌하단 가장자리만" 헬륨이 새서 뜨거워진다(`day1_3d_wafer_demo.png` 해설).
  3. **전체 파이프라인 1장 요약:** `[이상 감지] → [원인 찾기 + 오진 거르기] → [안전하게 히터 다시 맞추기] → [진짜 3D 시뮬레이션으로 재확인]`.
  4. **자주 묻는 질문 선제 정리:** "프로젝트 이름에 PINN이 있는데, Phase 1에는 왜 신경망이 없고 Phase 2에 들어가나?"

### Chapter 2. 반도체 ESC 열전달 기초: 왜 일반 대류($h$) 대신 '희박 헬륨'을 쓰는가?
* **학습 목표:** 웨이퍼–ESC 사이 $10\ \mu\text{m}$ 틈새의 물리(Kennard–Yovanovich)와 현장 안전 규칙(누설 시 승압 금지)을 학부 열전달 언어로 설명할 수 있다.
* **출발점 (학부 지식):** 1D 열저항 직렬 회로($R = L/kA$), 대류 열전달계수 $h$, 복사 $\varepsilon\sigma(T^4 - T_{\text{wall}}^4)$, Biot 수($\text{Bi} = hL/k$).
* **세부 내용:**
  1. **진공에서 열이 안 통하는 문제:** 진공 챔버 안에서 웨이퍼를 척에 그냥 올려두면 접촉 면적이 작아 열이 안 빠진다 → 뒷면에 헬륨(He) 가스를 10~15 Torr로 채워 열다리(Thermal Bridge)를 만든다.
  2. **희박 기체와 Kennard–Yovanovich 식의 직관:** 압력이 낮아지면 기체 분자끼리 부딪히기 전 이동 거리(평균자유행로 $\lambda$)가 $10\ \mu\text{m}$ 틈새만큼 커진다 → 겉보기 간극이 $d$에서 $d + M(P)$로 넓어지는 효과($h_{\text{He}} = k_{\text{He}} / (d + M(P))$).
  3. **왜 누설이 나면 에지 온도가 5.8°C나 튀는가?** 압력 $P\downarrow \Rightarrow \lambda\uparrow \Rightarrow M\uparrow \Rightarrow h_{\text{He}}\downarrow \Rightarrow \Delta T = q''/h_{\text{He}}\uparrow$.
  4. **현장 3대 안전 제약의 물리적 이유:**
     * 히터는 데우기만 가능($Q_i \ge 0$),
     * 누설 시 He 압력 승압 금지(척킹력 급감 + 파셴 아킹),
     * 세라믹 열충격($\text{Al}_2\text{O}_3$는 열전도도가 낮고 깨지기 쉬움).
  5. **코드 연결:** `src/physics/materials_and_he.py`, `src/fem3d/esc_3d_fem_solver.py`.

### Chapter 3. 속도 27배의 비밀: 선형 ESC ROM(중첩의 원리) + 2D 극좌표 FVM
* **학습 목표:** 3D FEM 전체를 매번 풀지 않고도 오차 `0.04°C`로 27배 빠르게 푸는 "선형/비선형 분리 결합" 원리를 이해한다.
* **출발점 (학부 지식):** 선형 미분방정식의 중첩의 원리(Superposition), 열전달의 얇은 판 근사(Lumped/Fin, $\text{Bi}_z \ll 1$), 유한체적법(FVM: 들어온 열 = 나간 열).
* **세부 내용:**
  1. **3D FEM(FEniCSx)의 장점과 한계:** 12만 개 요소로 정확하지만 1회 1.2초 → 역설계로 수백 번 돌리면 너무 느리다.
  2. **도메인 해부(선형 vs 비선형):**
     * **ESC(세라믹+Al 베이스+칠러):** 열전도도 상수 + 선형 냉각 → **100% 선형!** 히터 1 W 켰을 때의 온도 반응(영향행렬, Mode A ROM)을 딱 한 번만 미리 구해두면, 어떤 히터 조합이든 행렬 곱셈 한 번으로 끝!
     * **웨이퍼($775\ \mu\text{m}$):** 두께 방향 $\text{Bi}_z \approx 0.01 \ll 0.1$이라 위아래 온도 차가 `0.05°C`뿐 → 3D 대신 **2D 원판 극좌표 $(r, \theta)$ FVM(864셀)**으로 축약 가능!
  3. **양방향 결합(Schur 소거)과 에너지 보존:** 웨이퍼가 ESC로 넘긴 열이 ESC 온도를 올리고, 그게 다시 웨이퍼 온도를 바꾼다 → 선형 방정식 1번으로 정확히 묶고, "들어온 열 = 나간 열" 오차를 `1e-13 W`까지 확인.
  4. **코드 연결:** `src/rom/esc_3d_unit_load.py`, `src/solvers/coupled_3d_wafer_fvm.py`.

### Chapter 4. 미분 가능 물리(Differentiable Physics)와 수반법(Adjoint): 기울기가 514배 빨라지는 원리
* **학습 목표:** PyTorch 안에서 물리 방정식을 미분하는 이유와, 유한차분(FD) 대비 Adjoint법이 변수 개수에 상관없이 압도적으로 빠른 수학적 원리를 이해한다.
* **출발점 (학부 지식):** 다변수 함수의 연쇄법칙(Chain Rule), 음함수 미분($F(x, p) = 0 \Rightarrow dx/dp = -F_x^{-1} F_p$), Newton–Raphson 반복법.
* **세부 내용:**
  1. **역설계에 기울기($\partial T / \partial Q_i$)가 꼭 필요한 이유:** 히터 10개 + He 압력 2개 = 12개 다이얼을 무작정 돌려서는 못 맞춘다. "어느 다이얼을 얼마나 돌려야 온도가 내려가는지" 방향(기울기)을 알아야 한다.
  2. **유한차분(FD)의 비효율:** 12개 변수를 조금씩 흔들어 보려면 3D FEM을 최소 24번(약 29초) 돌려야 1걸음 간다.
  3. **음함수 정리와 수반법(Adjoint)의 마법:** Newton 반복 과정 전체를 미분하지 않고, 수렴한 정답 지점에서 $F_x^T \lambda = v$ 선형 방정식을 **딱 1번**만 풀면 12개(심지어 100개라도!) 변수의 정확한 기울기가 `57 ms` 만에 한꺼번에 나온다.
  4. **Gradcheck가 왜 필수인가?** 미분 코드에 부호 하나만 틀려도 최적화가 망가진다 → FD와 비교해 상대오차 `1.02e-9` 검증한 의미.
  5. **코드 연결:** `coupled_3d_wafer_fvm.py`의 `torch.autograd.Function`과 `step1_3d_hybrid_verify.py`.

### Chapter 5. 역문제(Inverse Problem)와 오진 차단: 왜 '한 번 더 재보기(Pre-Refit Gate)'가 필요한가?
* **학습 목표:** 65개 온도 센서와 He 유량으로 숨겨진 고장을 찾는 원리와, 단일 측정만 믿었을 때 발생하는 오진(Nullspace 함정)을 2-운전점 탐색으로 막는 원리를 이해한다.
* **출발점 (학부 지식):** 최소제곱법(Least Squares), 미지수 개수 vs 방정식 개수, 센서 노이즈(가우시안 분포).
* **세부 내용:**
  1. **정문제(Forward) vs 역문제(Inverse):** "히터·누설을 알 때 온도 구하기"는 쉽지만, "온도만 보고 원인을 거꾸로 찾기"는 어렵다(불량 조건, Ill-posed).
  2. **왜 온도만 보면 헷갈리는가?** 에지가 뜨거울 때 "플라즈마가 쏠린 건지, He이 새는 건지" 비슷해 보인다 → 장비 He 유량 로그를 함께 보고, 심지어 유량계에 $\pm 20\%$ 오차(Model Mismatch)가 있어도 버티게 설계한다.
  3. **가장 중요한 함정 — `test_15_ood_warpage`(웨이퍼 휨) 사례 해설:**
     * 단일 운전점에서는 웨이퍼 휨을 "플라즈마가 좀 세진 것"으로 그럴듯하게 착각해서 오차($S_0=77.3$)가 작게 나온다!
     * **해결책(Pre-Refit Gate):** 원인을 다시 맞추지 말고, He 압력을 안전하게 3 Torr만 낮춰본다(`u_probe`). 진짜 플라즈마 문제였다면 예측대로 온도가 변하겠지만, 웨이퍼 휨이었기 때문에 예측과 실측이 크게 어긋나며($S_{\text{probe}}=479.3$) 즉시 오진을 잡아낸다!
  4. **코드 연결:** `src/inverse/stage1_3d_diagnosis.py`.

### Chapter 6. 안전 제약 역설계(SLSQP)와 통계적 안전 보증($A_{\text{pre}}$, $V$, Clopper–Pearson)
* **학습 목표:** 현장 안전 규칙을 수학적 제약식으로 바꾸는 방법과, "0/68 위반 = 95% 신뢰수준에서 오승인율 4.31% 미만"이라는 통계적 안전 보증의 의미를 설명할 수 있다.
* **출발점 (학부 지식):** 라그랑주 승수법/제약 최적화, 평균·표준편차($3\sigma$), 이항분포(동전 던지기 확률).
* **세부 내용:**
  1. **SLSQP 제약 최적화 직관:** "웨이퍼 온도 편차를 줄이되(목적함수), 히터 음수 금지·누설 시 승압 금지·세라믹 구배 제한(제약조건)의 울타리를 절대 넘지 말라."
  2. **보수적 마진($\delta_T$)과 Operable Envelope 2D 맵 해설:** 1D/2D 축약 오차와 진단 불확실성까지 여유분($\overline{\rho} \le 0$)으로 얹어 승인한다. `phase15_operable_envelope.png`를 보며 "누설이 32%(`β=0.68`) 넘어가면 왜 히터만으로는 못 살리고 `Hold`로 빼야 하는지" 이해.
  3. **사전 승인($A_{\text{pre}}$) vs 사후 독립 검증($V$)을 왜 분리하는가?** (시험 문제 답안지를 미리 보고 채점하는 순환 오류 방지!)
  4. **Clopper–Pearson 95% 신뢰상한의 직관:** "68번 연속 불량이 0건이면, 진짜 오승인율이 4.31%보다 클 확률은 5% 미만" ($1 - 0.05^{1/68} = 0.0431$).
  5. **코드 연결:** `src/inverse/stage2_3d_recovery.py`, `benchmarks/phase15_verification_suite.py`.

### Chapter 7. PINN은 어디로 가는가? (Phase 1 물리 기준선 vs Phase 2-A PINN 비교 가이드)
* **학습 목표:** 표준 PINN, Data-only MLP, 그리고 우리가 구현한 Differentiable Hybrid(Mode A/Mode B)의 차이를 명확히 비교하고, Phase 2-A에서 무엇을 실험할지 이해한다.
* **출발점 (학부 지식):** 신경망 기초(입력→은닉층→출력, Loss 줄이기).
* **세부 내용:**
  1. **3가지 대리 모델의 직관적 비교표:**
     * `Data-only MLP`: 데이터만 외우는 학생 (빠르지만 처음 보는 극한 누설에서 헛소리).
     * `Soft-PINN`: 데이터 + 물리 방정식 숙제(PDE Loss)를 같이 푸는 학생 (물리를 배우지만 ESC 2D 물리와 충돌할 수 있음).
     * `Hybrid Mode A/B (Differentiable Physics)`: 물리 방정식 계산기(FVM)를 손에 쥐어주고, 복잡한 2D/3D ESC 부분만 ROM(Mode A)이나 신경망(Mode B)이 담당하게 하는 분업 구조.
  2. **Phase 2-A에서 우리가 증명할 핵심 질문:** "정말로 Hybrid Mode B가 Soft-PINN이나 MLP보다 적은 데이터로 더 정확하고 외삽이 잘 되는가?"
