# 5장. 역문제(Inverse Problem)와 오진 차단: 왜 '한 번 더 재보기(Pre-Refit Gate)'가 필요한가?

## 1. 학습 목표 및 출발점

순문제와 달리 현장에서는 센서 측정값만으로 보이지 않는 에지 헬륨 누설($\beta_{\text{leak}}, \theta_{\text{leak}}, r_{\text{leak}}$)과 플라즈마 입열($Q_{\text{plasma}}, \alpha_{\text{peak}}$)을 찾는 **역문제(Inverse Problem)**를 풉니다. 미지수보다 온도 센서(65개)가 많아 최소제곱법으로 쉽게 풀릴 것 같지만, 가우시안 노이즈($\sigma_T = 0.2^\circ\text{C}$)와 모델 외 고장(OOD)이 겹치면 단일점 적합만으로는 치명적 오진이 발생합니다. 이번 장에서는 **역문제 사기 방지**, **Nullspace 오진**, **하향 감압 Pre-Refit Gate의 차단 원리**를 익힙니다.

## 2. 핵심 개념 (3-Step 전개)

먼저 핵심 지표 $S_0, S_{\text{probe}}$는 **"각 센서 오차를 센서 노이즈 크기($0.2^\circ\text{C}$)로 나눈 뒤 제곱해 더한 정규화 오차 점수"**입니다. 모델이 물리를 잘 맞히면 점수가 작고, 이상이 숨어 있으면 점수가 폭증합니다(8건 캘리브레이션 잠금 문턱: $S_0 \le 107.154$, $S_{\text{probe}} \le 170.972$).

### Step 1. 역문제 사기 방지: 65점 SensArray와 유량 Model Mismatch

가상 데이터 생성식과 진단 모델이 같으면 비현실적인 **역문제 사기(Inverse Crime)**가 됩니다. 이를 막기 위해 65점 2D SensArray($\sigma_T = 0.2^\circ\text{C}$)에 더해, 비선형 점성 유량($\pm 20\%$ 드리프트 포함)과 선형 근사식 사이에 의도적 **Model Mismatch**를 두었습니다.

```python
# src/inverse/stage1_3d_diagnosis.py (L183-L191)
def eval_he_flow_true_sccm(
    beta_leak: float,
    p_out_torr: float,
    delta_cal: float,
    flow_params: HeFlowModelParams = HeFlowModelParams(),
) -> float:
    """Ground-truth nonlinear viscous He leak flow [sccm] (before measurement noise)."""
    leak_term = flow_params.kappa_nl * (1.0 - beta_leak ** 2) * (p_out_torr ** 2) * (1.0 + delta_cal)
    return float(flow_params.m_base_sccm + max(leak_term, 0.0))
```

```python
# src/inverse/stage1_3d_diagnosis.py (L194-L200)
def eval_he_flow_proxy_torch(
    beta_leak: torch.Tensor,
    p_out_torr: torch.Tensor | float,
    flow_params: HeFlowModelParams = HeFlowModelParams(),
) -> torch.Tensor:
    """Stage 1 deliberately mismatched linear He leak flow proxy [sccm]."""
    return flow_params.m_base_sccm + flow_params.kappa_lin * (1.0 - beta_leak) * p_out_torr
```

이 불일치 속에서도 정상 누설(`test_08_leak_225_show`, $\beta_{\text{leak}} = 0.70, \theta_{\text{leak}} = 225^\circ$)은 8섹터 스캔과 Adjoint L-BFGS-B로 $\hat{\beta} = 0.6958, \hat{\theta} = 225.15^\circ$까지 복원됩니다.

### Step 2. 단일점 Nullspace 오진과 하향 감압 Pre-Refit Gate

웨이퍼 휨 고장(`test_15_ood_warpage`)처럼 모델 가정 밖의 고장(OOD)이 생기면, 최적화기가 누설·플라즈마 파라미터를 조합해 단일 운전점 온도를 억지로 끼워 맞출 수 있습니다(Nullspace 오진). 실제로 `test_15_ood_warpage`는 1차 적합에서 **$S_0 = 77.3 < 107.154$**로 문턱을 통과합니다.

이를 깨는 해법이 **안전한 하향 감압 탐색($P_{\text{out}} - 3\text{ Torr}$)** 기반 **Pre-Refit Gate**입니다. 가압은 헬륨 아킹(Arcing) 위험이 크지만, 하향 감압은 **아킹 위험이 전혀 없습니다(Zero arcing risk)**. 감압 후 파라미터를 다시 피팅하지 않고(**Pre-Refit**) 기존 추정값 그대로 두 운전점의 온도 차분($\Delta T$)을 비교하면, 웨이퍼 휨은 $h_{\text{eff}}(P)$ 반응이 어긋나 **$S_{\text{probe}} = 479.3 > 170.972$**로 폭발하며 100% 차단됩니다.

### Step 3. 3중 안전 게이트와 Phase 1.5 검증

Stage 1은 ① 활성 인터락 `H_block`(OEM He 유량 $\ge 20\text{ sccm}$ 또는 Readback 누락 시 `1`), ② 1차 게이트($S_0 > 107.154$), ③ Pre-Refit Gate($S_{\text{probe}} > 170.972$)를 순차 적용합니다. Phase 1.5 독립 87건 배치에서 **`H_block` 4/4 (100%)**, **OOD 6/6 (100%)**, **극심 누설 5/5 (100%)**를 전량 차단했습니다.

## 3. 교과서 이상 모델 vs 현재 코드의 타협점

> [!NOTE]
> **양산(HVM) 적용 시 고려할 3가지 타협점**
> 1. **오프라인 SensArray TC 웨이퍼 vs 인라인 HVM 센서**: 현재는 셋업·PM용 65점 SensArray 웨이퍼를 가정하나, 양산 중에는 웨이퍼에 센서를 붙일 수 없어 ESC 내부 소수 센서 기반 추정기로 확장해야 합니다.
> 2. **합성 유량 Model Mismatch 프록시**: 실제 천이 유동과 MFC 동특성 대신 이차 비선형식과 $\pm 20\%$ 정적 드리프트 프록시로 불일치를 모사했습니다.
> 3. **감압 탐색의 열적 안정화 시간**: 정상상태 솔버는 $P_{\text{out}} - 3\text{ Torr}$ 직후 평형 온도를 즉시 얻지만, 실제 챔버에서는 새 열평형 도달까지 수 초~수십 초의 안정화 시간과 스루풋 손실이 따릅니다.

## 4. 3줄 요약 및 면접 자가 점검 퀴즈

1. **$S_0, S_{\text{probe}}$와 Model Mismatch**: 노이즈($0.2^\circ\text{C}$) 정규화 잔차 제곱합을 쓰며, 비선형/$\pm 20\%$ 드리프트 유량 불일치로 역문제 사기를 막았다.
2. **Pre-Refit Gate**: 단일점($S_0 = 77.3$)을 통과한 웨이퍼 휨(`test_15_ood_warpage`)을 아킹 없는 하향 감압($P_{\text{out}} - 3\text{ Torr}$) 후 재적합 없는 차분 검증($S_{\text{probe}} = 479.3 > 170.972$)으로 100% 차단했다.
3. **Phase 1.5 실적**: 3중 게이트로 `H_block`(4/4), OOD(6/6), 극심 누설(5/5)을 전량 차단해 오진 복구를 방지했다.

**면접 자가 점검 퀴즈:**
Q. 단일점 $S_0$가 문턱을 통과했는데도 왜 하향 감압($P_{\text{out}} - 3\text{ Torr}$)을 추가 측정하며, 이때 파라미터를 다시 피팅(Refit)하지 않고 $S_{\text{probe}}$를 계산해야 하는지 인과관계를 설명하세요.
