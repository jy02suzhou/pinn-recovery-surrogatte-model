# Chapter 4. 미분 가능 물리(Differentiable Physics)와 수반법(Adjoint): 기울기가 514배 빨라지는 원리

## 1. 학습 목표 및 출발점

앞 장에서 웨이퍼-ESC 순방향 대리 모델을 완성했습니다. 이제 **역설계**로 목표 온도 $T_{\text{target}} = 40.0^\circ\text{C}$와 균일도를 맞추려면 10존 히터 $Q_1 \sim Q_{10}$과 He 압력 $P_{\text{in}}, P_{\text{out}}$ 등 12개 다이얼의 손실 기울기 $\nabla_{\mathbf{u}}\mathcal{L}$가 필요합니다. 다변수 연쇄법칙, 음함수 미분, Newton-Raphson을 결합해 기울기를 **514.5배** 가속하는 **미분 가능 물리**와 **수반법(Adjoint)** 원리를 익힙니다.

## 2. 핵심 개념 (3-Step 전개)

### ① 직관: 12D 중앙유한차분 vs 수반법 `linalg.solve` 1회

12개 변수를 중앙유한차분으로 미분하면 $\pm\epsilon$ 섭동으로 해석을 24회 돌려야 합니다. `medium` 3D FEM(`1,228.2 ms`) 기준 $24 \times 1.228\text{ s} = 29.48\text{ s}$가 걸립니다. 반면 Newton-Raphson 수렴해 $T_w^*(\mathbf{u})$는 $F(T_w^*, \mathbf{u}) = 0$을 만족하므로, **음함수 미분과 수반법**을 쓰면 선형방정식 `linalg.solve` **1회**로 변수가 12개든 100개든 모든 기울기를 동시 산출합니다. 대리 모델 Forward(`45.63 ms`)와 12D Adjoint Backward 합계는 **`57.29 ms`**로 **`514.5x`** 가속됩니다.

### ② 핵심 수식

$F(T_w^*, \mathbf{u}) = 0$을 $\mathbf{u}$로 전미분해 $J\frac{dT_w^*}{d\mathbf{u}} + \frac{\partial F}{\partial \mathbf{u}} = 0$ ($J = \frac{\partial F}{\partial T_w}$)을 얻고, 수반 벡터 $\boldsymbol{\lambda}$를 도입하면 핵심 식은 두 줄입니다.

$$J^T \boldsymbol{\lambda} = \left(\frac{\partial \mathcal{L}}{\partial T_w}\right)^T, \qquad \frac{d\mathcal{L}}{d\mathbf{u}} = -\boldsymbol{\lambda}^T \frac{\partial F}{\partial \mathbf{u}}$$

### ③ 코드 연결과 2단계 Gradcheck

`src/solvers/coupled_3d_wafer_fvm.py`의 `_WaferImplicitSolveFn`은 `forward`에서 `torch.no_grad()`로 $T_w^*, J^*$를 저장하고, `backward`에서 수반 방정식을 풉니다.

```python
    def forward(
        ctx: Any,
        Q_heaters: torch.Tensor,
        p_in: torch.Tensor,
        p_out: torch.Tensor,
        beta_leak: torch.Tensor,
        Q_plasma: torch.Tensor,
        alpha_peak: torch.Tensor,
        theta_leak_deg: torch.Tensor,
        solver: "Coupled3DWaferFVMSolver",
        opts: SolveOptions,
    ) -> torch.Tensor:
        with torch.no_grad():
            T_w_star, J_star = solver._solve_newton_with_jacobian(
                Q_heaters=Q_heaters.detach(),
```

```python
    def backward(ctx: Any, grad_T_w: torch.Tensor):
        (
            T_w_star,
            J_star,
            Q_heaters,
            p_in,
            p_out,
            beta_leak,
            Q_plasma,
            alpha_peak,
            theta_leak_deg,
        ) = ctx.saved_tensors
        solver: Coupled3DWaferFVMSolver = ctx.solver
        opts: SolveOptions = ctx.opts
```

수반 도함수 오차는 최적화 발산으로 직결되므로 **Gradcheck는 최적화의 생명줄**입니다. `torch.float64`와 잔차 `< 1e-11` 수렴 후 `benchmarks/step1_3d_hybrid_verify.py`에서 2단계 검증을 수행합니다.

## 3. 교과서 이상 모델 vs 현재 코드의 타협점

> [!NOTE]
> 1. **`float32` 불가:** 유효숫자 약 7자리($\sim 10^{-7}$) 한계로 잔차 `< 1e-11` 도달이 불가능해 `torch.float64`를 강제합니다.
> 2. **`beta_leak` `8.19%` 편차:** 3D FEM의 에지 누설 경계가 DG0(요소별 상수)와 2 mm 램프로 이산화되어 국소 민감도 차이가 생깁니다.
> 3. **미수렴 Newton 금지:** $F(T_w^*, \mathbf{u}) = 0$이 깨진 상태에 음함수 미분을 쓰면 $dF=0$ 가정이 무너져 기울기가 왜곡됩니다.

## 4. 3줄 요약 및 면접 자가 점검 퀴즈

1. 음함수 미분과 수반법은 `linalg.solve` 1회로 12D 기울기를 동시 계산해 `29.48 s` → `57.29 ms`(`514.5x`)로 가속합니다.
2. `_WaferImplicitSolveFn`은 `forward`를 `torch.no_grad()`로 풀고 `backward`에서 $J^T\boldsymbol{\lambda} = (\partial\mathcal{L}/\partial T_w)^T$를 풉니다.
3. `torch.float64`·잔차 `< 1e-11` 수렴과 2단계 Gradcheck(`1.02e-9`, 3D FEM FD `0.46%`~`8.19%`)가 역설계 신뢰성의 핵심입니다.

**면접 자가 점검 퀴즈:** 히터 존을 10개에서 100개로 늘리면 중앙유한차분과 수반법의 1회 기울기 계산 비용은 각각 어떻게 변하며 그 원인은 무엇인가요?

<details><summary>정답 및 해설 보기</summary>

중앙유한차분은 변수 $N$개마다 $\pm\epsilon$ 해석이 필요해 $O(N)$으로 약 10배 폭증합니다. 반면 수반법의 $J^T\boldsymbol{\lambda} = (\partial\mathcal{L}/\partial T_w)^T$ 크기는 변수 수 $N$이 아니라 온도 자유도(`864`셀)에만 의존하므로, 변수가 100개여도 선형방정식은 **1회**만 풀어 비용이 사실상 $O(1)$입니다.
