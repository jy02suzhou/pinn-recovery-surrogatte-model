# Chapter 7. PINN은 어디로 가는가? (Phase 1 물리 기준선 vs Phase 2-A PINN 비교 가이드)

## 1. 학습 목표 및 출발점

Phase 1·1.5 대리 모델은 **신경망이 없는 순수 미분가능 물리 모델(Differentiable Physics / Hybrid ROM-FVM, Mode A)**입니다. 그런데 왜 프로젝트명에 `PINN`이 들어 있을까요? "신경망으로 3D FEM을 바로 학습하면 더 간단하지 않을까?"라는 질문에 답하기 위해, ① `MLP`, `Soft-PINN`, `Hybrid Mode A/B`의 차이를 직관적으로 구분하고 ② **Mode A 물리 기준선**에서 Phase 2-A 4종 비교·Phase 2-B 소재 일반화로 이어지는 설계 논리를 익힙니다.

## 2. 핵심 개념 (3-Step 전개)

### ① 직관 비유: 열전달 시험을 치르는 세 학생

신경망은 입력–은닉–출력층을 거쳐 오차(Loss)를 줄이는 함수 근사기입니다. 3D ESC·웨이퍼 열전달 시험을 치르는 세 학생에 비유해 봅시다.

* **기출 암기 학생 (`Data-only MLP`):** 3D FEM 정답만 보고 입력($Q_1 \sim Q_{10}, P_{\text{in}}, P_{\text{out}}, \beta_{\text{leak}}$)과 $T_w$를 통째로 외웁니다. 학습 구간에서는 빠르지만 낯선 $\theta_{\text{leak}}$나 경계 밖에서는 열수지를 어깁니다.
* **PDE 숙제 병행 학생 (`Soft-PINN`):** 데이터 Loss에 웨이퍼 PDE 잔차 벌점을 더합니다. 신경망 하나가 웨이퍼와 ESC를 함께 근사하므로 Loss 균형 잡기가 어렵고 정밀도가 흔들립니다.
* **물리 계산기 + 분업 팀 (`Hybrid Mode A/B`):** 웨이퍼 2D Polar FVM(`24×36=864`셀)은 **미분가능 계산기(`Diff-FVM`)**가 전담해 열수지(`1.14e-13 W`)를 원천 보장합니다. 하부 3D ESC 응답($T_{\text{ESC}}$)만 분리해 고정 물성은 **Mode A(선형 ROM, `M=82`)**, 소재·형상 확장 시에는 **Mode B(Neural ESC)**로 교체합니다.

### ② 왜 Mode A 기준선이 먼저인가? — Phase 2-A·2-B 설계 논리

신경망을 평가하려면 **물리 기준선**이 먼저 필요합니다. Phase 1·1.5 **Mode A**는 3D FEM(`1,228.2 ms`) 대비 Forward `45.63 ms`(`26.9×`), 12D Adjoint 포함 `57.29 ms`(`514.5×`), MAE `0.041°C`(정상)/`0.063°C`(225° 누설), 87건 위반 `0/68`(`0.00%`, 단측 95% 상한 `0.0431`)을 달성했습니다. 고정 $\text{Al}_2\text{O}_3$($k_{\text{cer}}=30\text{ W/m}\cdot\text{K}$) 장비에서는 선형 중첩이 정확해 **Mode A가 속도와 정밀도에서 가장 유리**합니다.

Phase 2-A는 **4종 모델을 2단 성적표(1단: 순방향 오차·열수지·속도, 2단: 폐루프 복구율·3D FEM 위반률)**로 비교합니다: `Data-only MLP`, `Soft-PINN`, `Linear ESC (POD+Ridge)+Diff-FVM`, `Hybrid Mode B (Neural ESC+Diff-FVM)`.

**Mode B가 필수적인 순간**은 **Phase 2-B**처럼 $k_{\text{cer}}$가 $\text{Al}_2\text{O}_3$($30\text{ W/m}\cdot\text{K}$) $\leftrightarrow$ $\text{AlN}$($160\text{ W/m}\cdot\text{K}$)으로 바뀔 때입니다. Mode A는 $k_{\text{cer}}$마다 FEM 기저(`13.88 s`)를 재추출해야 하지만 Mode B는 $k_{\text{cer}}$ 조건 입력으로 즉시 $T_{\text{ESC}}$를 예측합니다.

### ③ 코드 매핑: Mode A → Mode B 단일 교체 인터페이스

`src/solvers/coupled_3d_wafer_fvm.py`의 `Coupled3DWaferFVMSolver.solve`(617~631행)는 제어 입력을 모두 `torch.Tensor`로 변환해 PyTorch autograd 그래프에 올립니다.

```python
    def solve(
        self,
        Q_heaters: torch.Tensor | np.ndarray | tuple[float, ...],
        p_in: torch.Tensor | float = 12.0,
        p_out: torch.Tensor | float = 12.0,
        beta_leak: torch.Tensor | float = 1.0,
        Q_plasma: torch.Tensor | float = 500.0,
        alpha_peak: torch.Tensor | float = 0.25,
        opts: SolveOptions = SolveOptions(),
        theta_leak_deg: torch.Tensor | float | None = None,
    ) -> dict[str, torch.Tensor]:
        """Solve coupled 3D ESC + 2D Polar Wafer FVM with exact end-to-end autograd."""
        Q_htr_t = _as_f64_tensor(Q_heaters, self.device)
        p_in_t = _as_f64_tensor(p_in, self.device)
        p_out_t = _as_f64_tensor(p_out, self.device)
```

내부의 Mode A 선형 ESC 행렬만 미분가능한 Mode B Neural ESC로 교체해도, 12D Adjoint(Gradcheck `1.02e-9`)와 폐루프 최적화 파이프라인을 그대로 쓸 수 있습니다.

## 3. 교과서 이상 모델 vs 현재 코드의 타협점

> [!NOTE]
> **Soft-PINN의 구조적 약점과 `POD+Ridge` 공정 기준선**
> 교과서 `Soft-PINN`은 PDE 하나로 모든 입출력을 구속합니다. 그러나 10존 히터 $Q_1 \sim Q_{10}$은 **세라믹 내부 열원**일 뿐 **웨이퍼 PDE에 직접 등장하지 않습니다.** 웨이퍼 PDE는 $T_{\text{ESC}}$와 $h_{\text{eff}}$만 보므로 웨이퍼 PDE 잔차만으로는 $Q_i \to T_{\text{ESC}}$ 경로를 제약할 수 없습니다.
>
> 또한 Mode B를 침습형 FEM 기저(Mode A)와만 비교하면 데이터 조건이 달라 불공정합니다. 동일 오프라인 데이터로 학습하는 **비침습 선형 모델 `POD+Ridge+Diff-FVM`**을 함께 둬야 신경망의 순수 일반화 이득을 공정하게 평가합니다.

## 4. 3줄 요약 및 면접 자가 점검 퀴즈

* **요약 1:** Phase 1·1.5 **Mode A**는 신경망 없이 선형 ROM과 미분가능 FVM을 결합해 속도(`514.5×`)와 안전성(위반 `0/68`)을 입증한 기준선입니다.
* **요약 2:** $Q_i$가 웨이퍼 PDE에 직접 없는 다층 문제에서는 `Soft-PINN`보다 `Diff-FVM`과 ESC 연산자를 분업하는 **Hybrid 구조**가 유리합니다.
* **요약 3:** 단일 소재는 **Mode A**가 최적이며, Phase 2-A 4종 2단 성적표와 Phase 2-B($\text{Al}_2\text{O}_3 \leftrightarrow \text{AlN}$) 일반화에서 **Mode B**가 빛납니다.

**면접 퀴즈:** *"Mode A가 이미 MAE `0.041°C`, 위반 `0%`인데 왜 Phase 2에서 Mode B를 도입하며, 왜 `Soft-PINN` 대신 `Hybrid Mode B`를 택했나요?"*

<details><summary>정답 및 해설 보기</summary>

1. **Mode B 도입 이유:** 고정 $\text{Al}_2\text{O}_3$($30\text{ W/m}\cdot\text{K}$)에서는 Mode A가 최적이지만, $k_{\text{cer}}$가 $\text{AlN}$($160\text{ W/m}\cdot\text{K}$)으로 바뀔 때마다 FEM 기저(`13.88 s`)를 재추출해야 합니다. Mode B는 $k_{\text{cer}}$를 조건 입력으로 받아 즉시 일반화합니다.
2. **Soft-PINN 대신 Hybrid 이유:** $Q_1 \sim Q_{10}$이 웨이퍼 PDE에 없어 `Soft-PINN`은 히터–ESC 전도를 제약하지 못합니다. `Hybrid Mode B`는 웨이퍼 열수지를 `Diff-FVM`(`1.14e-13 W`)에 맡기고 신경망은 ESC 응답에만 집중시켜 정밀도와 미분 안정성을 확보합니다.

</details>
